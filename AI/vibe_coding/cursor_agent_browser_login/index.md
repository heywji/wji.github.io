# 项目：Cursor Agent Browser 登录方案

## 这是什么

这是一个用 Cursor IDE 内置 MCP Browser 工具完成网页登录的项目入口，当前手头最明确的例子是：

- 收奖网登录

它属于 Vibe Coding 项目，不是因为它只是“自动化脚本”，而是因为它把这些东西揉在了一起：

- Cursor Agent Browser 工具调用
- 页面元素定位
- 截图
- AI 视觉辅助识别验证码
- 登录后状态验证
- Playwright 本地等价验证

## 来源

当前项目主要来自这个本地文件：

- `wenkangnas_sojiang/test_login_browser.py`

## 当前工作流

这条线的核心流程是：

1. 打开登录页
2. 获取页面元素引用
3. 填用户名
4. 填密码
5. 点击验证码输入框，触发验证码图片
6. 截图验证码
7. 用 AI 视觉或人工读取验证码
8. 填入验证码
9. 点击登录
10. 检查 URL 是否跳转到目标页面

## 为什么适合放进 Vibe Coding

因为它不是单一技术点，而是一套“可被 AI 继续复现”的工程工作流：

- Cursor Agent Browser 负责页面交互
- AI 视觉负责验证码读取
- Playwright 作为本地验证兜底
- 页面跳转和 DOM 状态作为验收标准

## 可以沉淀成手册的主题

后面可以继续拆成：

1. Cursor Agent Browser 登录模板
2. 验证码处理与截图工作流
3. MCP Browser 与 Playwright 的对照手册
4. 登录成功与失败的验收规则

## 验收标准

至少应当能验证：

1. AI 能按步骤完成页面交互
2. 验证码流程可重复
3. 登录后 URL 能跳转到目标页面
4. 页面出现登录成功后的标志信息
5. 如果失败，能拿到失败截图或错误信息

## 备注

这一页只做项目入口，不直接放账户密码、验证码图片或 `.env` 中的敏感信息。
