# ChatGPT System Prompt Snapshot

来源：[`../System_Prompt`](../System_Prompt)

## 用途

这是我本地保留的一份 ChatGPT system prompt 快照，适合拿来做这些事：

- 回看当时 ChatGPT 的工具说明和回答风格约束
- 对比不同阶段 system prompt 的结构变化
- 提炼自己写 agent system prompt 时常见的分层方式

## 观察重点

- 工具区怎么写能力边界
- 浏览器、Python、图片能力怎么分开描述
- 回答风格、人格、时间信息怎么塞进 system prompt
